# 时间规划（Product Owner 工作 + Passion Project）

## 基本前提
- PO 工作：每天约 3 小时
- Passion project：Tukkata Tong Petpayathai 网站（`app/`、`content/` 等）
- 去办公室：每周在周二、周三、周四中选 2 天，默认是 **周二 + 周四**
- 其余时间在家办公

## 每周节奏
| 日 | 地点 | 重点 |
|---|---|---|
| 周一 | 家 | 上午：本周 PO 优先级 + passion 本周目标；下午：passion 深度工作 |
| 周二 | 办公室（默认） | PO 会议、面对面沟通；通勤时间做轻量 passion（看素材、写文案草稿） |
| 周三 | 家 | Passion 深度工作日（一周里最长的整块时间） |
| 周四 | 办公室（默认） | PO 会议、和 stakeholder 对齐 |
| 周五 | 家 | 上午 PO 收尾；下午 passion 上线/发布 + **周回顾（20 分钟）** |

> 如果某个办公室日改成在家（比如今天），就按下面的“居家日模板”过。

## 居家日模板
| 时间 | 内容 | 说明 |
|---|---|---|
| 09:00–09:15 | 晨间规划 | 在 thread 里告诉我今天的会议和 1–3 个 passion 目标 |
| 09:15–12:15 | **PO 块**（3h） | 会议 + backlog/工单/回复消息，PO 工作尽量都放这里 |
| 12:15–13:30 | 午饭 + 休息 | 离开屏幕 |
| 13:30–15:30 | **Passion 深度块 1** | 关掉 Slack/Teams 通知 |
| 15:30–15:45 | PO 消息检查 | 只处理紧急的，其他的留到明天的 PO 块 |
| 15:45–17:30 | **Passion 块 2** | 做实现、内容、发布 |
| 17:30–17:40 | 收工 check-in | 告诉我今天做了什么，我来汇总 |

## 办公室日模板
- 到公司后：PO 工作 + 会议（3h 以上也正常，人在公司就把要当面聊的事都聊完）
- 通勤/午休：轻量 passion（灵感、文案、看参考）
- 晚上：可选，最多 1 小时 passion，不要硬做

## 防忙乱的规则
1. **每天 passion 目标最多 3 个**，做完 1 个就算这一天没白过
2. PO 消息每天只集中看 3 次：开始 PO 块时、15:30、收工前
3. 会议被插到下午 → 用同样长度的上午时间换 passion，不要硬加班
4. 一天里 PO 超过 4 小时 → 在 log 里标记，周回顾的时候看是什么原因

## 时间分类（log 里用）
- `PO-会议`、`PO-执行`（backlog、文档、回复消息）
- `Passion-开发`、`Passion-内容`（写作、视频、图片）、`Passion-规划`
- `通勤`、`休息`、`其他`
