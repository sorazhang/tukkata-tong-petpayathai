# 训练感悟 · Training Insights

Muay Thai 训练中的感悟，持续累积，作为将来做 Reels 的素材库。

## 怎么记录

在 Claude session 里直接说出 / 打出感悟（中英文都可以，越口语越好）。
Claude 会整理成一条记录，追加到 `log.md` 并 commit。

## 每条记录的格式

```
## YYYY-MM-DD · 一句话标题

**原话：** 当时说的原话（保留语气，不改写）
**感悟：** 整理后的核心意思（1–3 句）
**场景：** 什么训练 / 哪个动作 / 跟谁练（如有）
**Reel 角度：** 可以拍成什么样的短视频（hook / 画面 / 金句）
**标签：** #技术 #心态 #身体 #泰国文化 #kru ...
```

## 标签参考

- `#技术` 动作、组合、距离、节奏
- `#心态` 害怕、坚持、自我怀疑、突破
- `#身体` 疲劳、伤痛、恢复、呼吸
- `#kru` 教练说的话
- `#文化` 泰拳礼仪、Wai Kru、泰国生活
- `#日常` 训练营日常、小故事
